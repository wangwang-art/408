音频质检工具 使用说明
========================================

一、适用环境
  - Windows 10 / 11（64 位）
  - 首次使用需联网运行"一键配置.bat"下载 Python 运行环境（约 200MB）

二、使用步骤
  1. 把整个文件夹复制到任意位置（路径建议不含中文和空格，避免个别程序异常）。
  2. 首次使用：双击运行"一键配置.bat"
     脚本会自动从国内镜像下载 Python 运行环境并安装全部依赖，全程无需手动操作。
     配置完成后无需再次运行（除非删除了 runtime 文件夹）。
  3. 双击运行"一键启动.bat"
     脚本会直接使用已配置的 Python 启动程序。
     几秒后程序自动打开浏览器，地址为 http://127.0.0.1:7860
     如果未自动打开，请手动在浏览器输入该地址。

三、注意事项
  - 首次启动需加载 AI 模型，浏览器会在服务就绪后自动打开；
    若提前打开显示"拒绝连接"，等终端出现"Running on local URL"后再刷新即可。
  - runtime 文件夹由"一键配置.bat"自动生成，请勿手动删除；
    如需重新配置，删除 runtime 文件夹后再次运行"一键配置.bat"即可。
  - 防火墙弹窗：首次启动如提示允许网络访问，请选择"允许"。
  - 端口被占用：本程序默认使用 7860 端口（Flask 版用 5000 端口），
    如启动提示端口被占用或无法打开页面，请先双击运行"释放端口.bat"，
    它会自动结束占用 7860 / 5000 端口的进程，之后再启动即可。
    注意：运行前请确认没有其他重要程序正在使用这两个端口。
  - 窗口一闪而过：多为被杀毒软件拦截或文件夹被移动不完整，请关闭杀毒软件
    或重新解压完整包后再试。

四、说明
  - 本工具便携版：通过"一键配置.bat"下载 Python 3.12 与全部依赖
    （gradio、onnxruntime 等），对方电脑不装 Python 也能运行，
    不受系统 Python 版本/商店版影响。
  - 本工具包含 Gradio 版（默认启动，端口 7860）与 Flask 版（app_ai_quality_flask.py，端口 5000）。
  - 如需使用 Flask 版，双击"启动Flask版.bat"，或手动执行：
      runtime\python\python.exe app_ai_quality_flask.py
  - DNSMOS 模型文件（sig_bak_ovr.onnx、model_v8.onnx）已随仓库提供，无需额外下载。
  - 运行日志保存在包内隐藏目录 data\.logs 中：
      一键启动（Gradio 版）→ app_7860.log；Flask 版 → app_5000.log。
    程序启动异常时可在该日志中查看具体报错；删除整个文件夹时日志一并清除。
  - 删除整个文件夹即可完全卸载，不会残留系统文件。
