# 时间日记 (Time Diary)

二次元风格的时间记录应用（纯 HTML/CSS 单页应用），奶油暖底 + 蜜桃珊瑚主色 + 樱花粉点缀，参考「爱时间」的信息架构 × 二次元轻量插画氛围。

## 页面

| 页面 | 说明 |
|---|---|
| `onboarding.html` | 欢迎引导页 |
| `timeline.html` | 时间轴（按时间线查看记录） |
| `diary.html` | 日记 |
| `record-edit.html` | 记录编辑 |
| `category.html` | 分类管理 |
| `goals.html` | 目标列表 |
| `goal-edit.html` | 目标编辑 |
| `stats.html` | 统计 |
| `profile.html` | 个人主页 |

## 使用

直接用浏览器打开 `pages/` 下任意 HTML 页面即可，无需构建、无需安装依赖。

## 目录结构

```
pages/            # 页面（纯 HTML，样式内联 + 共享 CSS）
assets/           # 图片资源（插画、贴纸、背景图）
colors_and_type.css  # 全局设计令牌与样式
```
