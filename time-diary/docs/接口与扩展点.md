# 时间日记 · 接口与扩展点总览

> 适用版本 v1.2.3+。所有共享脚本以 UMD 模式挂载到全局命名空间 `TD.*`（浏览器 window / node globalThis），无 ES Module、无构建步骤。
> 原则：上层依赖下层；UI 不直接碰存储；Domain 纯函数；DB 接口全异步。改任何接口前先读本文对应小节。

## 一、分层接口

### 1. Config（js/config/constants.js）
唯一常量来源，页面禁止散落定义。

| 成员 | 说明 |
|---|---|
| `APP / VERSION / SCHEMA_VERSION` | 应用标识、版本号、schema 版本（升级结构必须递增） |
| `KEY_PREFIX / KEYS` | 存储键（`td:` 前缀 + 各实体键），存储层唯一寻址依据 |
| `PALETTE / MOODS / PERIODS / GOAL_TYPES` | 色板、心情枚举、目标周期枚举、目标类型枚举 |
| `DEFAULT_SETTINGS / DEFAULT_CATEGORIES` | 首次种子（分类 id 用英文常量，禁止中文当主键） |
| `ROUTES / NAV_ITEMS` | **路由表**（页面键 camelCase ↔ 路径 kebab-case），加页面只改这里 |
| `AUTOFILL_GAP_MS` | 自动补录回接窗口 |
| `AI` | **预留**：`{enabled:false, endpoint, model, apiKey}`，见 ai.js |
| `FALLBACK_CATEGORY` | 已删除分类的兜底显示 |

### 2. Utils（js/utils/）
| 接口 | 签名 | 说明 |
|---|---|---|
| `TD.uuid()` | `→ string` | uuid v4，主键生成唯一入口 |
| `TD.DateUtil.startOfDay/endOfDay(ts)` | `→ ts` | 本地时区天界；"天"用左闭右开区间 |
| `TD.DateUtil.dateKey/keyToTs/addDays` | `key↔ts` | 'YYYY-MM-DD' 本地日期键（禁用 toISOString） |
| `TD.DateUtil.startOfWeek(ts, weekStart)` | `→ ts` | 周起始（0=周日 1=周一） |
| `TD.DateUtil.startOfMonth/daysInMonth/isoWeek` | | 月/ISO 周 |
| `TD.DateUtil.formatHM/parseHM/formatCN` | | 'HH:MM' 与 'M月D日 周X' |
| `TD.Format.duration/durationShort/clock/hmRange/pct` | | '2小时30分' / '2h30m' / 'HH:MM:SS' / '75%' |

### 3. DB 层（js/db/）—— 换存储的唯一改造点
`TD.Storage`（全异步，返回 Promise，**上层禁止直接碰 localStorage**）：

| 方法 | 签名 | 约定 |
|---|---|---|
| `get(key, fallback)` | `→ Promise<any>` | JSON 损坏时返回 fallback 并清坏数据（防白屏） |
| `set(key, value)` | `→ Promise<true>` | 配额超限抛错（调用方 toast 提示导出备份） |
| `remove(key)` / `clearAll()` | `→ Promise` | clearAll 仅清 `td:` 前缀键 |

`TD.Migrations.run()`：读 `td:meta.schemaVersion`，低于 `Config.SCHEMA_VERSION` 就按 `table[版本]` 依次执行幂等迁移函数并写回。**加实体/改结构 = 迁移表加函数 + SCHEMA_VERSION 递增，别动其他层。**

> **扩展点：换 IndexedDB** —— 新建 `js/db/indexeddb.js` 实现同款 get/set/remove/clearAll 异步接口即可，Repository 与页面零改动。

### 4. Repository 层（js/repo/repositories.js）—— 上层唯一数据入口
通用 CRUD（每实体）：`list() / get(id) / upsert(item) / remove(id) / clear()`，upsert 自动维护 id/createdAt/updatedAt。

| 实体 | 附加接口 | 约定 |
|---|---|---|
| `TD.Repo.categories` | `active()`、`archive(id)` | **软删除**（archived=true），记录保留引用 |
| `TD.Repo.records` | `ongoing()`、`saveRecord(input)` | **硬删除**；`end=null` 即进行中（全局最多一条）；saveRecord 做重叠检测 |
| `TD.Repo.goals` | 通用 CRUD | type: 'duration'/'count'；period: 'daily'/'weekdays'/'weekly'/'once' |
| `TD.Repo.diaries` | `byDateKey(k)`、`upsertByDate(d)` | 按 dateKey 一天一篇 |
| `TD.Repo.settings` | `read()`（合并默认值）、`write(patch)` | theme/weekStart/onboarded |
| `TD.Repo.seedIfEmpty()` | | 首次种子（幂等），仅 boot 调用 |

### 5. 领域层（js/domain/）—— 纯函数，不碰存储/DOM，node 可测
| 模块 | 关键接口 |
|---|---|
| `TD.Domain.records` | `segments(records, rangeStart, rangeEnd, nowTs)`（**跨天读时裁剪**）、`daySegments`、`timelineBlocks`（自动补 gap）、`totalMinutes`、`byCategory`、`lastEnd`、`activeDayKeys`、`streakDays` |
| `TD.Domain.goals` | `periodRange`、`isActiveOn`、`weeklyMinutes`、`progress(goal, records, dayTs, nowTs, weekStart)`、`weekOverview`、`habitWeek` |
| `TD.Domain.stats` | `summarize(byCat, categories) → {total, items[]}`、`ledger(segments, categories)`、`insights(summary, opts) → string[]`（**规则版洞察，与 AI 版签名对齐**） |

### 6. 服务层（js/services/）
| 服务 | 接口 | 说明 |
|---|---|---|
| `TD.Notify.toast(msg, type?)` | type: 'error' | 同消息 2.5s 内去重 |
| `TD.Notify.confirm(title, msg, kind?) → Promise<bool>` | kind: 'danger' | **压入一条历史**：返回键先关弹窗不退页 |
| `TD.Notify._forceClose()` | | 路由切页时关闭残留弹窗（内部用） |
| `TD.Backup.build() / download()` | | 导出 JSON `{app, schemaVersion, exportedAt, data}` |
| `TD.Backup.validate(text) → {ok, payload?, error?}` | | 纯校验，node 可测 |
| `TD.Backup.importFromText(text) → Promise<bool>` | | 校验→确认→写入→补跑迁移 |
| `TD.AI`（**预留，默认关闭**） | `enabled() / analyze(summary) → Promise<string[]> / buildContext(summary)` | 与 `Domain.stats.insights` 签名对齐可互换；**只发聚合不发明细**；启用步骤见 ai.js 头注释 |

### 7. UI 层（js/ui/、js/router.js）
| 接口 | 签名 | 说明 |
|---|---|---|
| `TD.Router.start(settings)` | | 唯一启动入口：迁移→种子→守卫→渲染 |
| `TD.Router.go(key, params?) / replace / back` | | 跳转统一出口；params 进 hash query |
| `TD.Router.href(key, params?) / parse(hash) / params / current` | | href 供链接填充；params 为当前路由参数 |
| `TD.UI.query()` | | 当前路由参数（页面读取参数唯一方式） |
| `TD.UI.renderNav(pageKey)` | | 底部导航（固定悬浮 + 安全区） |
| `TD.UI.bindBack() / wireLinks()` | | `data-action="back"`、`data-go="routeKey"` |
| `TD.UI.donut(el, items)` | | 自绘 SVG 环形图 |
| `TD.UI.catFinder(categories) → fn(id) → 分类` | | 含已删除兜底 |
| `TD.UI.pageToken() / still(token)` | | **页面生命周期令牌**（见下） |
| `TD.Theme.apply/set/toggle` | | 切换带 200ms 颜色过渡 |
| `TD.Viewport.init()` | | 键盘（.kb-open 隐藏底栏）/ 横竖屏防抖 |

### 8. 页面接入约定（js/pages/）
| 项 | 约定 |
|---|---|
| 模板 | `TD.TPL[key] = '<main>...</main>'`，资产路径 `assets/...`，页面私有样式内嵌 `<style>` |
| 初始化 | `TD.Pages[key] = async function (settings) {...}`，由路由器在挂载后调用 |
| 取参数 | `UI.query()`（如 `#/record-edit?id=&date=&ongoing=1`） |
| 取元素 | `document.getElementById`（单视图架构，挂载后全局唯一） |
| 生命周期 | init 开头 `var token = UI.pageToken()`，**每个 await 后 `if (!UI.still(token)) return;`**；定时器注册进 `TD._leaveHook`（切页自动清理） |
| 标题 | `TD.TITLES[key]`（app.js 中集中定义） |

## 二、存储 Schema（v1）

| 键 | 结构 |
|---|---|
| `td:meta` | `{schemaVersion: 1}` |
| `td:settings` | `{theme, weekStart, onboarded}` |
| `td:categories` | `[{id, name, color, icon, parentId, sort, archived, createdAt, updatedAt}]` |
| `td:records` | `[{id, categoryId, start, end(null=进行中), note, createdAt, updatedAt}]` 毫秒时间戳 |
| `td:goals` | `[{id, categoryId, name, type, targetMinutes, targetCount, period, startDate, endDate, reminder, ...}]` |
| `td:diaries` | `[{id, dateKey, title, mood, content, createdAt, updatedAt}]` |
