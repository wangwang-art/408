# ComfyUI 工作流

基于 ComfyUI 的 AI 绘画工作流定义（JSON 格式，可直接导入 ComfyUI 使用）。

## 工作流列表

| 文件 | 说明 |
| --- | --- |
| `real to anime.json` | 写实照片转动漫风格工作流 |
| `videoflow H3.json` | 视频处理工作流（H3 版本） |
| `z-image.json` | 图像生成工作流（z 系列） |

## 使用

在 ComfyUI 界面中，将对应 JSON 文件直接拖入画布，或通过 Workflow 导入菜单加载即可使用。
