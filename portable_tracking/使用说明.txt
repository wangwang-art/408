使用说明（手 / 脸 / 身体 三追踪便携版）
=======================================

一、本包是什么
本文件夹是一个"零安装"便携分发包，内置了 Python 运行时（runtime/python）和全部依赖（mediapipe、opencv-python），
不需要目标电脑安装 Python，也不需要联网安装任何东西，拷走即用。

二、使用方法
0. 从 GitHub 下载的源码版不包含 runtime 文件夹，请先双击根目录的"一键配置.bat"，自动下载内置 Python 并安装依赖（需联网，使用国内镜像），完成后即可继续。
1. 把整个 portable_tracking 文件夹复制到目标电脑的任意位置（U 盘、桌面、D 盘均可，路径不要有空格或括号最好）。
2. 进入对应的子文件夹，双击"一键启动.bat"：
     hand_tracking\一键启动.bat   手部追踪（最多 2 只手，21 个关键点连线）
     face_tracking\一键启动.bat   脸部追踪（478 个关键点网格）
     body_tracking\一键启动.bat   身体追踪（33 个关键点骨架）
3. 程序会自动打开摄像头并开始实时追踪。

三、退出方式
在预览窗口中按键盘 q 键退出。
如果不想让程序运行，也可以直接关闭预览窗口，或在启动时直接关闭黑色命令行窗口。

四、常见问题
- 打开后提示"无法打开摄像头，请检查摄像头设备是否可用"：
  说明当前电脑没有可用摄像头，或摄像头被其它程序占用（如微信、腾讯会议）。
  请关闭占用摄像头的程序后重试，或检查摄像头驱动。
- 首次运行需要几秒初始化模型，请耐心等待。
- 请勿单独移动子文件夹中的文件，整个文件夹要保持完整一起拷贝。
